# L'Agent (version navigateur)

Jeu court à la première personne de Hadrien Basch. three.js + Vite.

    npm install
    npm run dev        # http://127.0.0.1:5190  (?x=&y=&z=&yaw=&pitch= pour placer la caméra, ?noPost, ?noAO)

La rue (pack Fab sous licence) n'est pas dans ce dépôt : voir docs/ASSETS.md. Sans elle, le jeu affiche un sol neutre.
Personnages : `tools/characters/build.sh` (pip install bpy==5.2.2, ImageMagick).
